# Algorytm genetyczny dla problemu komiwojażera

Implementacja algorytmu genetycznego w Javie do eksperymentalnego rozwiązania problemu komiwojażera.

## Uruchomienie

W katalogu `Algorytm` otwórz projekt jako zwykły projekt Java i uruchom klasę `src/Main.java`.

## Struktura

- `Algorytm/src` - implementacja algorytmu i operacji wejścia/wyjścia
- `Algorytm/data` - zestawy danych TSP oraz wyniki eksperymentów
